# 七类手绘原型预览

打开 `outputs/prototype_review/handdrawn_v2/gallery.html` 查看本轮结果。
每类四栏依次为候选物理道路、原始感知、模拟感知 A、模拟感知 B。
绿线为待审核候选 GT，橙线是原 Guide；灰色车道线、黑色路沿、红色停止线、紫色斑马线。

## 生成方式

```bash
python scripts/build_handdrawn_prototype_review.py \
  --output-dir outputs/prototype_review/handdrawn_next --seed 71107
```

输出目录必须不存在，避免覆盖既有审核结果。脚本只生成小批预览，不启动模型推理或训练。
`SPECS` 定义七个源存档和当前候选连接；`geometry` 独立构造道路与 81 个约 1m 间隔的目标点。
三个增道场景共享 2→4 的候选道路，分别固定左、中、右三个目标连接。
其余场景暂用固定车道数和单个 pose；路口只建立行驶连接走廊，尚未重建完整四臂道路。

## 必须先确认的假设

- 手绘内容始终是感知观测；候选 World/GT 是人工提出的假设，不能称为恢复出的真实道路。
- 候选 GT 在感知扰动前固定，不从有噪声的线段中点生成，也不随 Guide 逐点切换目标车道。
- 原始 `input.json` 和 `scene.json` 按字节复制，原存档不改动；原 Guide/nav 保持不变。
- 不再按 FOV 裁剪。模拟观测的可见段由手绘片段投影到候选道路的区间提出，允许端点变化。
- 片段与物理线暂按同类最近距离匹配，可能多对一；不是已确认的道路身份。
- 每片段以 65% 概率施加平顺倾斜/弯曲，另有轻微平移；长度足够时以 30% 概率生成内部缺口。
  这些概率和幅度是本轮审核参数，尚未校准，也没有修改共享感知器。
- 停止线、斑马线沿用原观测，没有建立对应的物理真值。

## 输出与验证

每类包含 `comparison.png`、原输入及场景副本、两个模拟输入、`world_hypothesis.json`、
`reference_candidate.json` 和 `annotation.json`。GT 独立存放，未写进模型输入。
注释记录匹配距离、噪声事件、源文件哈希与限制。

生成时检查目标在候选道路内、采样间距、输入有限值、32-token 容量，以及 GT 不影响输入编码。
`tests/test_handdrawn_prototype_review.py` 另检查共享增道道路、固定目标、可复现性和不裁剪侧向 30m 观测。
这一批仅供审核，不是可直接混入训练的数据集；道路形态和目标连接确认后再扩展车道数、姿态与样本量。
