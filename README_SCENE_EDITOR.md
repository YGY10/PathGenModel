# BEV 场景编辑器

人工存档 `outputs/scene_editor/20*/` 中的工程、输入、PNG 和 NPZ，以及 `gallery.html` 已配置为 Git 可跟踪。
新增存档保存后仍需提交和推送才能换电脑同步；浏览器测试、服务日志/PID和其他实验输出保持忽略。

在项目根目录启动，使用已有 torch310 环境，不需要安装前端依赖：

```bash
conda activate torch310
python scene_editor.py --background --open
```

界面地址：<http://127.0.0.1:8765>。可通过 `--port 8766` 改端口，`--output-dir outputs/my_editor_cases` 改保存位置。只监听本机。使用 `--background` 后，关闭终端和浏览器都不会停止服务；启动信息会显示 PID 和日志路径（`outputs/scene_editor/server_<时间>/`），需要停止时执行 `kill <PID>`。省略 `--background` 则在前台运行，Ctrl+C 停止。
若服务已经启动，直接打开地址即可，不必再次启动。

## 画线和修改形状

1. 左侧选择 Guide line、GT path、BEV line 或 BEV curb。另支持停止线与斑马线的矩形区域。
2. 平滑曲线：点击“在画布绘制”，依次点击起点和终点。选中后拖动两个端点或两个空心形状控制点；右侧也能直接输入控制点坐标。
3. 也可展开“用坐标指定起点 / 终点”，输入 x、y 后添加。坐标单位米：x 向前，y 向左；画布向上为前，向左为左，自车固定在 (0,0)。
4. 折线：选择折线模式，逐点绘制，按 Enter 或点击“完成绘制”结束。选中折线后双击线段插入节点，或用右侧按钮插入、移除节点。
5. 滚轮缩放，空格+拖动或鼠标中键平移；“适合场景”显示完整场景。可开启 0.5m 吸附。
6. 支持撤销/重做，Delete 删除选中元素。一个场景只允许一条 Guide；Guide起点不会被自动归零。

## GT 编辑与导出

左侧选择绿色 `GT path · 目标路径`，与普通线一样绘制折线或平滑曲线，拖动控制点、输入坐标、旋转和删除。
也可点击“复制 Guide 为 GT”，生成独立对象并将其起点对齐自车原点（Bezier 同时移动起点控制柄），不修改原 Guide。
每场景最多一条 GT；GT 可选，不画仍能保存并推理。

GT 必须从 `(0,0)` 开始，长度至少 80m，导出为沿弧长每米采样的 `gt_path[81,2]`。
长度不足或起点偏移时拒绝保存并提示修改，不拉伸、不外推、不裁 FOV。
GT 不进入 BEV token 和模型输入，只作为评估/训练标签；PNG 和采样预览显示绿色目标。
编辑草稿允许未完成 GT，保存 `scene.json` 保留控制点。导入旧 `gt_path` 自动升级为可选中编辑的折线。

## 方向键平移线和 box

先点击画布或元素列表选中对象，再按方向键按画面方向整体平移：↑ 为 x 增大，← 为 y 增大。
默认每次 0.1m，Shift+方向键为 1m，Alt+方向键为 0.01m；同时按 Shift/Alt 时采用微调步长。
支持所有线、Guide、GT、停止线和斑马线区域；全部控制点/顶点一起移动，形状保持不变。
长按同一方向键的连续移动合为一步撤销，支持重做。在输入框、下拉框、文本编辑区内不触发对象平移。
正在绘制或拖动时不触发；GT 整体平移后如起点偏离自车，需要在保存前调整回原点。

## GT 局部居中参考

选中绿色 GT 后，右侧显示此工具。选择参考模式，指定目标车道边界（车道线或路沿），填写开始、结束里程和两端过渡长度。
里程按当前 GT 从起点累计的弧长计算，不是纵向 x 坐标。仅对自己认可的可信边界勾选确认，再点击“预览参考”。

三种模式：双侧取中点、左侧向右偏移、右侧向左偏移。每侧列表支持 Ctrl / Cmd 多选片段，
如一个左边界配两个首尾相接的右边界片段。同侧片段应描述同一条车道边界，不要混选相邻车道。
左右不能选同一对象；单侧模式不使用另一侧列表的选择。

紫色虚线为候选 GT，青色为几何参考。双侧沿 GT 局部切线的法向求两侧线段交点，取中点；
不按点编号配对，因此允许边界采样不一致、点序相反和弯道。单侧先沿边界自身法向偏移，再与GT局部横截面求交。
单侧距离须大于0且不超过8m，可直接指定；也可输入假定车道宽并点击“取宽度一半”（如3.5m→1.75m）。
假定宽度不是测量结果，尤其路沿与车道边线不重合时，应自行指定所需距离。

所用各侧片段的覆盖并集须覆盖整个所选区间；独立片段不跨缺口连线，首尾相接交点会去重。
遇到缺口、所需侧缺失、冲突重叠或多重交点时拒绝生成，不外推缺失边界；双侧车道宽须在1–8m。
这只是所选感知边界的几何参考，不能保证是真实道路中心；有意画歪的感知不能用于精度标定。

确认后点击“应用到 GT”，只修改选中区间，用五次平滑权重在两端向原路径过渡；过渡长度须大于0且不超过区间一半。
区间外几何保留，Guide 和 BEV 不修改。应用后 GT 变成密集折线，导出仍按修正后的弧长采样81点；
路径长度变化可能使后方同编号采样点位置变化，不代表区间外几何被改动。
预览期间不会修改工程；调整相关对象或参数会使预览失效，必须重新预览。

首次应用前的完整 GT（模式和控制点）保存在 `scene.json` 的 GT 元素 `original_handdrawn` 内，
每次应用还记录 `centering_history`（模式、左右片段ID列表、单侧偏移、区间及原路径）；不会进入 `input.json` 或模型特征。
“恢复原手绘GT”可恢复首次应用前的形状，应用与恢复均可撤销/重做。取消参考仅隐藏预览。
保存新场景后原手绘备份可随工程重新导入；原存档不覆盖。

先尝试路口直行例 `20261107_230623_690212/scene.json`：选 `line_1` 为左边界、`line_2` 为右边界，
里程30–65m、过渡5m。这只是操作示例，请自行确认边界是否可信。更新后需重启旧服务并刷新（先下载草稿）。

## 邻线距离

选中 Guide、车道线或路沿后，画布与右侧会显示测点到最近邻线的距离（米）。拖动端点或控制柄时实时更新；移动鼠标可沿选中线检查不同位置。测点投影在实际曲线上，不把控制柄本身当作道路上的点。
默认比较车道线和路沿，排除 Guide；也可切换“仅车道线”或“所有线（含 Guide）”。“参照线”可从自动最近线切换为指定ID；即使旁边有更近的路沿，也始终测所指定的线，并在画布上高亮参照。删除参照或切换类型使其不可选时，恢复自动测量。例如希望两条平行车道线约相隔 3.5 m，可选择“仅车道线”边拖边看数值。
这是**当前测点到邻线的最短直线距离**，不是全线最小间距，也不是道路法向宽度。弯曲、分流、相交、断裂或错开的端点会影响数值；辅助线显示实际测量位置，请沿线多处检查。Guide 到车道线的距离通常不能直接当车道宽度。

## 服务断开与草稿恢复

顶部显示本地服务连接状态，每 10 秒检查一次。若保存时出现 `Failed to fetch`，通常是启动编辑器的进程已退出；页面上的绘图仍可继续，但模型采样和磁盘保存需要服务。
新版会明确提示连接失败，并立即尝试将当前工程保存到本浏览器。点击“下载编辑草稿”也可在断网、后台退出时直接下载原始工程，无需后台服务。
重新执行 `python scene_editor.py --background` 后，在原页面重试保存即可；无需重画。更新编辑器代码后先下载草稿备份，再刷新页面加载新版，必要时重新导入草稿。刷新恢复依赖同一浏览器、同一地址且允许本地存储。

## 旋转线条和区域框

选中元素后，在右侧“旋转选中元素”选择支点，输入角度后点击“应用角度”，或使用左右5°按钮。正角度向左、负角度向右。支点可选元素中心、起点、终点或自车原点；Guide默认以起点为支点，其他元素默认以实际几何按线长计算的中心为支点（矩形为其中心），连续旋转时支点保持稳定。
旋转同时变换Bezier所有控制点或区域框所有顶点，保留曲线形状、线长和矩形形状；支持撤销/重做。旋转后的坐标就是保存和模型采样使用的坐标。

## 语义和导航

- BEV line：置信度 0–1、白/黄/未知颜色、实/虚/未知线型。
- BEV curb：置信度 0–1；不人为添加车道线颜色和线型。
- Guide：仅几何，不使用 BEV 置信度、颜色或实虚线属性。
- 停止线/斑马线：闭合区域和置信度；与现有编码器一致。
- 在左侧选择 straight、left 或 right 导航后保存。

## 保存与自动采样

点击“保存模型输入”，生成一个新的 `outputs/scene_editor/<时间>/`，不覆盖已有文件：

|文件|用途|
|---|---|
|`input.json`|可直接传给现有 infer.py 的输入；Guide为81点，BEV保留曲线几何和语义，推理时由现有编码器统一采样|
|`scene.json`|保存原始控制点、线形、导航和属性，方便下次继续编辑|
|`scene.png`|完整编辑场景的自动取景图片，含名称、导航、元素ID、米制坐标、自车和Guide；不受当前画布视角影响|
|`model_input.npz`|实际编码快照：bev_points [32,32,6]、point_mask、polyline_mask、polyline_attr [32,10]、guide [81,2]、navigation；单样本无batch维度|

Guide沿曲线弧长每1m采样，取前80m的81个点；总长不足80m明确报错，不拉伸、不外推。建议把绘制终点放在85m或更远，留足覆盖。
BEV复用现有 `infer.encode_input`，避免独立实现与训练不一致；保留曲线几何的JSON不提前重复重采样，实际32点输入保存在NPZ。超出32个元素按训练编码器规则筛选，界面显示实际保留数量。
“预览模型采样”以圆点叠加实际Guide/BEV采样位置。每次保存还会更新 `outputs/scene_editor/gallery.html`，可直接用浏览器打开缩略图总览，点击看大图并下载原稿；保存成功后也能在界面点“查看保存的场景图 PNG”。图片画完整编辑几何，较粗的Guide为导出的前80m，不包含模型预测。

为已有存档补图（只添加缺失的scene.png，不改JSON、不覆盖已有PNG）：

```bash
python scene_editor.py --backfill-previews
```

保存后界面会生成并可复制推理命令，例如：

```bash
python infer.py \
  --checkpoint outputs/training_road_mixed_v2/best.pt \
  --input outputs/scene_editor/<时间>/input.json \
  --device cuda
```

编辑器本身不加载模型权重、不启动训练或GPU推理。

## 导入和草稿

“导入 JSON”支持已有 `input.json`、紧凑自定义JSON和本工具的 `scene.json`。建议优先导入 `scene.json`，可保留平滑曲线控制柄；普通输入按已有采样点导入为折线，保持原几何。
“载入分流示例”读取 examples/custom_input_split.json 的当前版本，不改写它。
“下载编辑草稿”可保存未完成、Guide不足80m的编辑工程；浏览器也会尝试自动保存最近草稿。
若导入包含 gt_path，该 GT 自动转换为绿色可编辑对象，不参与模型输入；修改感知与 Guide 后请核实 GT 是否仍符合目标意图。
