# 自定义场景存档

这里保存人工绘制的感知片段、Guide 与 GT，随 Git 仓库同步，供跨电脑继续编辑和固定案例评估。
打开 `gallery.html` 浏览存档；编辑时优先导入各目录的 `scene.json`。

每个时间戳目录保存：

- `scene.json`：可编辑工程，包括曲线控制点、GT 及已应用参考的手绘备份。
- `input.json`：模型推理输入和可选 GT 标签，GT 不作为输入特征。
- `scene.png`：场景预览。
- `model_input.npz`：导出时生成的模型输入编码快照。

文件夹名是唯一存档标识，场景名称可能重复。不同存档可能是同一原型的多个版本，
不能把这些版本随机拆到训练和验证两侧；此目录不是现成的训练集。
手绘 GT 表达人工意图，不等同于测绘精度真值；用感知边界生成的参考也受观测误差影响。

Git 忽略浏览器测试目录、服务日志与 PID，以及此目录之外的实验数据和训练输出。
以后保存的新时间戳场景也会出现在 Git 未跟踪文件中，需要正常 `git add`、提交和推送才会同步。
