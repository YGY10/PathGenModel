GT 局部居中参考

Ctrl / Cmd 多选；同侧片段应属于同一条车道边界，不会跨缺口自动连接。

单侧距离为人工假设，不代表测得车道宽；路沿可直接填写所需偏移。

按原GT弧长选区间；不等同于向前距离。所需边界片段需覆盖整个区间。紫色为候选GT，青色为几何参考；不自动修改感知。

有意画歪的感知边界请勿使用。双侧支持1–8m车道，单侧偏移0–8m（不含0），缺口或交点歧义会拒绝生成。原手绘GT保存在工程内，操作可撤销。

旋转选中元素

正角度向左旋转，负角度向右；支持曲线、折线和区域框，可撤销。Guide 建议以起点为支点。

邻线距离

可锁定参照线；拖动时实时测量，悬停选中线可查看沿线间距。数值为该位置到邻线的最短直线距离，分流处会变化；不是整条线的最小间距。可用 3.5 m 作绘制参考。
